# บัญชีเงินของฉัน (แอปติดตั้งบนมือถือ)

## ไฟล์ในโฟลเดอร์
- `index.html` — ตัวแอป
- `manifest.webmanifest` — ชื่อแอป ไอคอน และการเปิดแบบเต็มจอ
- `sw.js` — เก็บแอปไว้ในเครื่องเพื่อใช้งานแบบออฟไลน์
- `icons/` — ไอคอนแอป

## ขึ้นเว็บฟรีด้วย Netlify (ง่ายที่สุด)
1. เข้า https://app.netlify.com/drop
2. ลากโฟลเดอร์ `ledger-app` ทั้งโฟลเดอร์ไปวาง
3. จะได้ลิงก์แบบ `https://xxxx.netlify.app` (สมัครบัญชีฟรีเพื่อให้ลิงก์อยู่ถาวร)

## หรือใช้ GitHub Pages
1. สร้าง repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ Settings → Pages → Branch: `main` / root → Save
3. ลิงก์จะเป็น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ติดตั้งลงมือถือ
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

## เรื่องข้อมูล
- ข้อมูลเก็บไว้ในมือถือเครื่องนั้นเท่านั้น ไม่ส่งไปที่ไหน
- กด "สำรองข้อมูล" เป็นประจำ ถ้าเปลี่ยนเครื่องให้กด "กู้คืนจากไฟล์"
- ถ้าแก้ไขไฟล์แอปแล้วอยากให้มือถืออัปเดตแน่นอน ให้เปลี่ยนค่า `VERSION` ใน `sw.js`
